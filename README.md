## 📖 Project Description

This project analyzes the open-source software **Git**. It covers its origin, license, Linux usage, ecosystem, and comparison with proprietary tools.
It also includes five shell scripts demonstrating core Linux concepts.

---

## 📜 Scripts Overview

### 🔹 Script 1 — System Identity Report

Displays system information like:

* Kernel version
* Current user
* System uptime
* Date

---

### 🔹 Script 2 — FOSS Package Inspector

* Checks if Git is installed
* Displays Git version and details

---

### 🔹 Script 3 — Disk and Permission Auditor

* Shows permissions of important directories
* Displays disk usage and sizes

---

### 🔹 Script 4 — Log File Analyzer

* Counts occurrences of a keyword in a log file
* Displays matching lines

---

### 🔹 Script 5 — Open Source Manifesto Generator

* Generates a personalized manifesto
* Based on user input
